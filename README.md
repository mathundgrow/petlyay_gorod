# Гуляй Город (Walk City) 🏙️

Мобильное приложение для исследования города и выполнения городских квестов.

## 🛠 Технологии
- **Фреймворк:** Flutter
- **Архитектура:** Feature-first
- **Бэкенд:** PocketBase
- **Состояние:** BLoC (в планах)

## 🚀 Основные возможности
- **Онбординг:** Увлекательное знакомство с функционалом приложения.
- **Авторизация:** Вход и регистрация пользователей.
- **Лента заданий:** Маршруты и миссии с гибкой фильтрацией.

## 🏗 Структура проекта
Проект организован по архитектуре `Feature-first`:
- `lib/features/onboarding` — экраны знакомства.
- `lib/features/auth` — авторизация и регистрация.
- `lib/features/home` — главная лента.
- `lib/core` — общие компоненты (кнопки, заголовки, сеть).

## 🛠 Как запустить 
1. Склонируй репозиторий: `git clone [твоя_ссылка]`
2. Установи зависимости: `flutter pub get`
3. Запусти сервер PocketBase локально.
4. Запусти приложение: `flutter run`
