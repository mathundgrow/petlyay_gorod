# Гуляй Город (Walk City) 🏙️

Мобильное приложение для городского ориентирования и квестов.

## Стек технологий 🛠
- **Frontend:** Flutter / Dart
- **Backend:** PocketBase (локальный сервер)
- **State Management:** BLoC (Business Logic Component)

---

## Архитектура 🏗 (Feature-First)

Проект разделен на независимые модули (фичи). Внутри каждой фичи соблюдается строгая слоистая архитектура. 

**Навигация по слоям:**
* [Слой Data](#-data)
* [Слой Domain](#-domain)
* [Слой Presentation](#-presentation)

### Data 📦
Данные приложения. Здесь хранятся:
- **Модели (Models):** классы-конверты для парсинга JSON от сервера.
- **Репозитории (Repositories):** логика общения с API PocketBase.
- **Локальный кэш:** например, записи флагов (прошел ли юзер онбординг).

### Domain 🧠
Business-rules (бизнес-логика и интерфейсы). 
Это чистый слой, который содержит правила работы приложения и абстрактныt классы ( репозиториев). Он полностью независим от внешних библиотек и UI.

### Presentation 📱
Displays (Пользовательский интерфейс).
Слой отвечает за всё, что видит пользователь:
- **UI:** Верстка экранов (`screens`) и переиспользуемые виджеты (`widgets`).
- **States:** Управление состояниями через BLoC (связка событий от пользователя и ответов от Data-слоя).

---

## Запуск проекта 🚀

1. Склонируйте репозиторий.
2. Скачайте и запустите бинарный файл `PocketBase` локально (`./pocketbase serve`).
3. Выполните команду `flutter pub get` для установки зависимостей.
4. Запустите приложение на симуляторе: `flutter run`.
